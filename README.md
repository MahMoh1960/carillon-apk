# Carillon (Android)
1. Déposez ce dossier à la racine du dépôt GitHub (branche main).
2. Onglet Actions > « Build APK » (se lance au push, ou à la main).
3. Téléchargez l'artefact « carillon-apk » (app-debug.apk) et installez-le.
Sur le téléphone : autorisez les notifications et les alarmes exactes, et désactivez l'optimisation de batterie pour l'application.
